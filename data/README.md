# Данные для запуска

Поместите в эту папку два CSV-файла из задания Marketpele:

| Файл | Содержание | Обязательные столбцы |
| --- | --- | --- |
| `user_activity_data.csv` | Историческая активность пользователей | `date`, `user_id`, `device`, `pages_viewed`, `paid_clicks`, `organic_clicks`, `revenue` |
| `experiment_data.csv` | Результаты эксперимента на уровне пользователя | `user_id`, `pages_viewed`, `paid_clicks`, `organic_clicks`, `revenue`, `device`, `ctr_paid`, `ctr_organic`, `group` |

Формат: CSV с заголовком, разделитель — запятая, десятичный разделитель — точка. Группы эксперимента обозначены `control` и `test`.

Исходные CSV не включены в репозиторий. Их нужно получить из материалов учебного задания. Сохранённые результаты доступны в ноутбуке без запуска, но для повторного выполнения нужны оба файла.

`ctr_paid` и `ctr_organic` в экспериментальном файле уже рассчитаны. В исторических данных ноутбук рассчитывает их как количество соответствующих кликов, делённое на `pages_viewed`.

Локальные данные исключены из Git через `.gitignore`.
